# Shuxrat Eshmurodov — Bepul video darslik (lending)

Telefon-birinchi, premium lending. Bitta katta CTA foydalanuvchini Telegram
botga yoʻnaltiradi va video darslik oʻsha yerda yuboriladi.

- **Stack:** Next.js 14 (App Router) · TypeScript · CSS tokenlar
- **CTA manzil:** `https://t.me/ShuxratEshmurodovBot?start=target_sayt_1`
- **Deploy:** Vercel

## Ishga tushirish

```bash
npm install
npm run dev
```

http://localhost:3000
